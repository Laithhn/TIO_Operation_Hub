## Not verified / known gaps

- Ten routes have no test that opens them directly (see the checklist): `/account/password`, five edit forms (`/products|contracts|environments|cases|escalations/:id/edit`), `/components/:id`, `/admin/groups` (Windows sign-in mode only) and the not-found page. They use the same frame and kit as the verified pages.
- Forms sign-in with real credentials was not exercised in the browser; the dev instance uses development sign-in.
- Raw page-level controls (`className="btn …"`, `input`, `select`) are framework-styled native elements, not vendored framework components. This is by design (see FRONTEND-ARCHITECTURE.md), and replacing them would remove form and accessibility capabilities.
- Text contrast:
  - calmingGreen (#5dae95) and attentionHigh (#e6932b) are used only as marker or fill colours, with dark text beside them.
  - The framework's weak text colour (primary at 65 % alpha) is about 5:1 on offWhite.
  - No automated contrast audit was run.
- No RTL or other languages: English only, as before.
- Bundle size grew by about 0.3 MB gzip; code-splitting the icon JSON is a possible follow-up.
