# TIO Hub ITSM concept mockups

This is a standalone design concept for strengthening ITSM workflows around service operations, SLAs, incident and problem management, change enablement, service configuration, and continual improvement.

Open `TIO-ITSM-Concept-Mockups.html` in a modern browser to explore the seven clickable screens. The prototype includes navigation, request details, work-queue tabs, and selectable configuration-map components. `TIO-ITSM-Concept-Mockups.pdf` is a seven-page landscape review pack, with one screen per page.

All records, people, metrics, and service names are fictional. The screens illustrate proposed workflows and are not evidence of current product capabilities. This prototype is isolated under `deliverables/itsm-mockups/`; it does not modify application source code, data, or configuration.
