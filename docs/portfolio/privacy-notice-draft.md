## 2. People and data categories

Depending on deployment and user practice, the system may process:

- user account identifiers, names, work contact details, roles, authentication and access events;
- customer/client organization and business contact details;
- cases, escalations, commitments, contract references, handover notes and operational history;
- audit records, report filters, export metadata and in-app notifications;
- files and attachments uploaded by authorized users;
- technical environment, inventory, version, infrastructure and network details.

Confirm actual categories, sensitive/special data, children’s data, data subjects, source and mandatory/optional fields for the deployment. Do not assume every installation contains all categories. Users must not enter passwords, access tokens, private keys or connection strings into normal business records.
