# TIO audit remediation (TIO-BUG-001 … 007)

11 November 2026. Corrections for the seven defects confirmed by the audit of the **deployed 2.59.0** application on 10 November 2026 (`tio-audit/`). The work was done on the local checkout at `fa71ace` (2.60.0 + A109/A110), which is newer than what the auditors saw; the decision record is **A111** in `docs/DECISIONS.md`.

**Status words used below**

- **Implemented and locally verified**: changed in this checkout, and the named regression tests ran and passed here, on synthetic data in isolated databases or with every HTTP request intercepted.
- **Verified in the deployed application**: none of the seven. No deployment was made, and nothing was run against the deployed site, its database, Jira, notifications, exports or schedules.

Every regression below that uses a database ran on the isolated LocalDB instance `(localdb)\TioHubQALocalDB`. Each run creates its own `TioHub_Test_*` database and drops it afterwards (owner's standing approval for that instance, 4 Nov 2026). No production record, ID, name or export reference from the audit evidence was used as a fixture.

## Historical audit entries (TIO-BUG-002)

The fix affects **new** audit entries only. Entries already written in production, such as the 10 Nov 2026 13:45 update of Jira user mapping 552, may still hold a temporary key. They were **not** rewritten, and the release contains no data step that changes them.

Proposed approved, append-only handling (needs the owner's and a DBA's approval; not executed):

1. **Read-only investigation.** A DBA reads the raw `audit.AuditEntry.Changes` text of the affected entries, without parsing them in a browser. They compare `JiraUserMapping.TioUserId` with the matching `User` Create entry (same `At` and `CorrelationId`).
2. **Correction.** Record the result as a new, separate entry, not as an edit. For example, an `AuditActionAsync`-style entry with action "Investigation note", the entity type and id of the mapping, and the reason "Entry #<id> recorded a temporary user key; the saved user id is <id>".
3. **Never** update or delete the original entries.
